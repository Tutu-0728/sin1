MOTION LAB // MECHANISM STUDY

正弦机构与正切机构的由来

从铰链四杆的摆动输出出发，通过引入移动副与改变接触几何，理解正弦、正切函数机构的形成过程。

MECHANISM LOGIC / 机构链路
曲柄摇杆机构 → 运动副替换 / 杆件槽化 → 正弦机构；正弦几何改变为定垂距接触 → 正切机构
ORIGIN 01 // SINE

正弦机构的演化

动画以曲柄摇杆为起点，展示输出端由转动接触转为受直线约束的移动接触，最终形成位移与 sinθ 对应的机构。

位移 ∝ sin θ
ORIGIN 02 // TANGENT

正切机构的演化

在函数机构基础上，将接触几何改变为相对摇轴保持恒定垂直距离的形式，形成位移与 tanθ 对应的输出关系。

位移 ∝ tan θ
